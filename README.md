# Landing Page

Адаптивная вёрстка лендинга по готовому макету.

## Стек

* HTML5
* CSS3
* JavaScript
* jQuery

## Реализовано

* Адаптивная вёрстка
* Версия для мобильных устройств
* Интерактивные элементы
* Семантическая разметка

## Запуск

Откройте `index.html` в браузере.
